# Actionability Checklist

When organizing a note, ask in this order:

1. In which active project will this be useful the soonest?
   - Move it to `Projects`.

2. If no project applies, which ongoing area does this support?
   - Move it to `Areas`.

3. If no area applies, is it useful as future reference?
   - Move it to `Resources`.

4. If it is inactive, outdated, completed, or no longer actionable:
   - Move it to `Archives`.

5. If unsure:
   - Leave it in `Inbox` and review it during the Weekly Review.
