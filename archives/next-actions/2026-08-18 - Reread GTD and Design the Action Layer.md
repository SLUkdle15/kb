# Reread GTD and Design the Action Layer

Area: [[areas/personal-development/personal-development|Personal Development]]

## Action

Reread the Getting Things Done philosophy and decide how it should actually work in this vault. Actions sit in [[next/next-actions/next-actions|Next Actions]] far too long — [[archives/next-actions/2026-07-16 - Refactor KB Trigger Notes Into Areas|the KB refactor]] has been open since 2026-07-16 and only surfaced because a lint run counted its age — so the gap is in the back half of GTD, not in capture.

Walk the five stages (capture, clarify, organize, reflect, engage) and write down for each one what this vault already does and what is missing:

- Clarify: is each note a real physical next action, or a vague outcome that stalls?
- Organize: do `next-actions`, `calendar`, `maybe`, and `waiting` need contexts (@errand, @laptop, @phone) or an energy/time hint to be pickable?
- Reflect: the weekly review exists as the `review` skill but is not running on a rhythm — decide what makes it happen.
- Engage: what do I look at when choosing what to do next, and does an action need an expiry or a re-decide date?

Keep the design compatible with the BASB side already written in [[resources/personal-knowledge-management/personal-knowledge-management|Personal Knowledge Management]].

## Decision — canceled 2026-08-19

Not rereading GTD. The action layer is not the problem: actions in this vault are sorted correctly under `next-actions`, `calendar`, `maybe`, and `waiting`, and no contexts or energy hints are missing.

The problem is that I do not follow the rule I already have. An action gets written and then left for months before it is looked at again — the KB refactor sat from 2026-07-16 to 2026-08-19 and only surfaced because a lint run counted its age.

So the gap is Reflect alone: nothing makes the review actually happen. Clarify, Organize, and Engage need no redesign, and no distilled GTD note is needed.
