# Set Up a Daily News Habit

Area: [[areas/personal-development/personal-development|Personal Development]]
Protocol: [[areas/personal-development/start-a-new-habit|Start a New Habit]]

## Action

Run the habit protocol for following news daily.

Decide first which news to follow — tech, business, or world. That choice is undecided and it sets the identity the habit proves, so everything downstream depends on it. Then write the cue, and cut the daily rep down to two minutes or less.

Checking against [[areas/personal-development/favorite-problems|Favorite Problems]]: this serves question 4, building a system that spots important ideas early.

## Done When

Sources are chosen, the cue is written as "I will [read X] at [TIME] in [LOCATION]" or stacked on an existing habit, a two-minute version of the rep is defined, and the first rep is done.
