# Book the IELTS Test for Early October

Project: [[projects/score-ielts-7-overall/score-ielts-7-overall|Score IELTS 7.0 Overall]]
Area: [[areas/personal-development/personal-development|Personal Development]]

## Action

Book an IELTS Academic slot for early October 2026 — target Saturday 3 October. Do this before any studying. Slots at popular centres fill weeks ahead, and the plan's whole shape depends on the date being real.

## Checklist

Decide the format:

- [ ] **Academic**, not General Training. A master's application needs Academic.
- [ ] **Computer-delivered**, not paper. Results land in 1 to 5 days instead of 13, which is what keeps a November retake possible if this one misses.
- [ ] Check whether the centre offers **One Skill Retake**. If exactly one of Writing or Speaking comes back below 6.5, this is the cheap fix — but it is only available at participating centres, so it changes which centre to book. Confirm before paying, not after.

Book it:

- [ ] Compare IDP and British Council for date, centre location, and fee.
- [ ] Check the Speaking slot. It may fall on a different day from the other three sections; both dates have to work.
- [ ] Confirm the ID document. The passport or ID used at registration must be the same one carried on test day, and the name must match exactly.
- [ ] Pay and get the confirmation.

Close the loop:

- [ ] Add the test date to [[next/calendar/calendar|Calendar]], with the Speaking date if it differs.
- [ ] Write the confirmed date into [[projects/score-ielts-7-overall/score-ielts-7-overall|the project note]] and adjust [[projects/score-ielts-7-overall/six-week-plan|the six-week plan]] if it is not 3 October.
- [ ] Note the results date and check it still clears the December 2026 application deadline in [[projects/pursue-a-masters-degree/pursue-a-masters-degree|Pursue a Master's Degree]].

## Done When

A paid booking confirmation exists with a named date and centre, the date is on the calendar, and the six-week plan has been shifted to match it.

Do this within the next few days. Every day the booking slips, either the plan gets shorter or the test gets later.
