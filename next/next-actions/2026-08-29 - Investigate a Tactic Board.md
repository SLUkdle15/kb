# Investigate a Tactic Board

Area: [[areas/soccer/soccer|Soccer]]
Area: [[areas/badminton/badminton|Badminton]]

## Action

Find out whether a tactic board is worth using for the weekly soccer match and for badminton doubles, and pick one if it is.

- What a tactic board is good for off the pitch or court: drawing formations, walking through rotations, reviewing a match afterwards.
- Whether one board covers both sports, or each needs its own.
- Options: a phone/tablet app, a small physical magnetic board, or just a notebook diagram.
- Which one fits how I actually use it — midfield positioning cues for soccer, doubles rotation for badminton.

## Done When

I can say whether a tactic board earns its place, and if so, which one I am using for each sport.
