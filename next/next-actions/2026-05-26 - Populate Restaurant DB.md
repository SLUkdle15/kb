# Populate Restaurant DB

Area: [[resources/restaurants/restaurants]]

## Action

Add initial restaurant notes to [[resources/restaurants/restaurants]] using the `restaurant-kb` skill.

## Done When

- At least 5 restaurants have notes in `resources/restaurants`.
- Each restaurant has location, cuisine, price, parking, best-for, and past-experience details where known.
- [[resources/restaurants/restaurants]] links to the created restaurant notes.
