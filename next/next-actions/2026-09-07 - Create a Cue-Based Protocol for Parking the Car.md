# Create a Cue-Based Protocol for Parking the Car

## Action

Build a step-by-step parking protocol anchored on concrete cues (mirror alignment points, where the wheel line crosses a reference, when to start turning, when to stop) rather than vague feel — the same shape as other protocol checklists in this vault. Cover the specific situations that need it: parallel parking, garage/tight-space parking, whatever is actually giving trouble.

## Done When

A written checklist of cues exists and has been tested against at least one real parking attempt.
