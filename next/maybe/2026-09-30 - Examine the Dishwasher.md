# Examine the Dishwasher

Area: [[areas/family/family|Family]]

## Action

Run through the dishwasher and pin down what is wrong: check the filter, spray arms, door seal, and drain, and note the model number and any error code or symptom.

## Done When

The problem is named — either fixed on the spot, or written down clearly enough to become a repair action or a call to a technician.
