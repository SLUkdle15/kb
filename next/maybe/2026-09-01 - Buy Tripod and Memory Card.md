## Action

Buy an all-in-one tripod compatible with GoPro 12, phone, and camera.

Add a memory card in the same purchase — the GoPro takes microSD, so check the capacity and speed class it needs for the video mode actually being used before buying.

## Done When

Tripod purchased and confirmed to work with all three devices, and a memory card is in the GoPro with room to record.
