# Twice-Weekly Lower Back Routine

Every: Monday and Thursday 21:00

## Action

- Glute bridge — 12 reps, 1 set
- Side plank from knees — 25s each side, 1 set
- Bird dog — 8 reps each side, 1 set
- Hip flexor stretch — 30s each side, 1 set

## Done When

Recurring — stays here while the routine is on.
