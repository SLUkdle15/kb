# Learn Photography

## Outcome

Comfortable shooting in full manual mode, without relying on auto or semi-auto settings.

## Definition of Done

- Can confidently set aperture, shutter speed, and ISO for a given scene without guessing.
- Can explain the exposure triangle and how the three settings trade off against each other.
- Has produced a set of manual-mode shots that turned out as intended.
