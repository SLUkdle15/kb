# Places I Have Looked At

Area: [[areas/photography/photography|Photography]]

A running list of places already scouted, so picking the next location is a choice from a list instead of a fresh search every time. The project approach is pick a place, find photos of it, mimic them — this note holds the first half.

## Places

One entry per place, added when it gets looked at. Fill in what there is to shoot, when the light is worth going for, and one or two reference shots to copy.

## Rule

Record a place when it is looked at, not when it is shot. A place that turned out not to be worth shooting still belongs here, with the reason — otherwise it gets scouted again in a month.
