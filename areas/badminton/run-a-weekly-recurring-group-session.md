# Run a Weekly Recurring Group Session

Source: [[archives/next-actions/2026-08-16 - Manage the Weekly Badminton Session with Girlfriend|Manage the Weekly Badminton Session with Girlfriend]]

## Checklist

- [ ] Line up enough players to make the slot worth running; know the minimum and the comfortable max.
- [ ] Promote the slot to a recurring `next/calendar` action once the above is settled.
- [ ] Retire the calendar action if the session stops running.

## Notes

- Round the per-head collection up to a clean number rather than the exact split; the small surplus covers rounding and the occasional no-show.
- Re-check the per-head cost whenever attendance settles at a different headcount than planned.
