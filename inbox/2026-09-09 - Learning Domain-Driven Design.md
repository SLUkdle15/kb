## Reading Questions

The roadmap's question for this phase is: where should the boundaries be?

1. When is DDD worth its cost compared to a simpler architecture, and when is it overkill? Which subdomains deserve the full treatment?
2. What is a Bounded Context, and how should it relate to deployment boundaries like microservices?
3. What can I test without a database or framework, and what does that reveal about where logic belongs?
4. How is the model discovered with domain experts, and how does the Ubiquitous Language show up in the code?
5. How big should an Aggregate be, and how do aggregates stay consistent with each other?
