
# Badminton Session — Break-Even Cost Sheet

**Setup:** 1 court, 2 hours, 6 shuttlecocks per session, 4 sessions/month
**Shuttle unit price:** 330,000 ÷ 12 = 27,500 VND

---

| Item                 | Per session | Per month (4 sessions) | Per person / session          |
| -------------------- | ----------- | ---------------------- | ----------------------------- |
| Court                | 210,000     | 840,000                | 35,000 (6p) / 30,000 (7p)     |
| Shuttles (6 pcs)     | 165,000     | 660,000                | 27,500 (6p) / 23,571 (7p)     |
| **Total out**        | **375,000** | **1,500,000**          | **62,500 (6p) / 53,571 (7p)** |
| Collected @ 6 people | 378,000     | 1,512,000              | **63,000**                    |

## Rules

- Announce the **total cost (375,000)**, not a fixed price — split among whoever shows up
- Minimum 5 people to run the session
- 6 shuttles included; extras split among players
- Small buffer goes toward the next box of shuttles
