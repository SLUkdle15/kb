# Badminton Practice Tracker

Related area: [[areas/badminton/badminton|Badminton]]

Use this to track badminton practice without turning every session into a project. Create a dated session note only when the session has useful feedback, drills, or decisions worth keeping.

## Capture Rule

- Record every session as one row in the Session Log.
- Normal self practice: update only this tracker.
- Important self practice: update this tracker and create a dated session note.
- Coach practice: update this tracker and create a dated session note.
- Match or game review: update this tracker and create a dated session note.
- Store detailed session notes in `resources/badminton` using `YYYY-MM-DD - Badminton Coach Practice.md` or `YYYY-MM-DD - Badminton Self Practice.md`.
