# Restaurants

Use this collection for places to eat and meal decision support.

## How To Use

Each restaurant gets a dated note in this folder with comparable attributes such as cuisine, location, price, parking, date suitability, and past experience.

When asking for a recommendation, include whatever matters today:

- Area
- Budget
- Transport or parking need
- Meal type
- Cuisine craving
- Companion
- Time available
- Things to avoid
