# Places

Use this collection to document non-food places you visit or want to discover: attractions, parks, viewpoints, shops, neighborhoods, and experiences. For places to eat, use [[resources/restaurants/restaurants|Restaurants]].

## How To Use

Each place gets a dated note in this folder with comparable attributes such as type, location, cost, and whether you've been. Set `Status` to `visited` or `to discover` so the list works as both a visit log and a discovery list.

When deciding where to go, include whatever matters today:

- Area
- Transport or parking need
- Time available
- Companion
- Indoor / outdoor
- Cost
- Mood or craving
