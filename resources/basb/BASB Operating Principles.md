# BASB Operating Principles

## PARA

PARA organizes knowledge by actionability:

- **Projects** are active outcomes.
- **Areas** are ongoing responsibilities.
- **Resources** are useful references.
- **Archives** are inactive material kept out of the way.

The same topic can appear in different places depending on what you need it for.

## CODE

CODE describes the flow of knowledge work:

- **Capture** what seems useful.
- **Organize** it where it can help soonest.
- **Distill** it into easier-to-reuse form.
- **Express** it through decisions, deliverables, systems, or creative output.

## Progressive Summarization

Progressive Summarization means improving a note in layers. Start with raw capture, then mark what matters, summarize what is most useful, and eventually turn it into something reusable.

Do not summarize everything. Distill when reuse is likely.

## Intermediate Packets

Intermediate Packets are small reusable pieces of work.

Examples:

- A decision record
- A diagram
- A checklist
- A paragraph of refined explanation
- A benchmark
- A meeting summary
- A research brief

They make future work faster because you can assemble outputs from material you have already shaped.

## Archipelago of Ideas

The Archipelago of Ideas approach starts a project by collecting existing notes, references, fragments, and questions before drafting from scratch.

Instead of facing a blank page, build islands of useful material, then connect them into an outline.

## Organizing for Actionability

A note belongs where it can create value soonest.

Ask:

- Which active project can use this?
- Which responsibility does this support?
- Is this reference material for later?
- Is this inactive enough to archive?

## Completion Over Perfection

The system should help you finish useful work, not maintain a perfect library.

A note is good enough when it helps you think, decide, create, or act.
