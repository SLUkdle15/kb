# Program a New Remote on the CT202 Gate Receiver

Area: [[areas/family/family|Family]]
Related: [[next/maybe/2026-08-09 - Examine the Door|Examine the Door]]

**Board:** Key Automation CT202 (chip marked CT202K02).
**Manual:** [[Key Automation CT202 Manual.pdf]] (580ISCT202 rev08, for 230 Vac motors)
**Where:** the small white plug-in radio receiver module on the green control board, next to the "RADIO RECEIVER" silkscreen label. It has one button and a green LED.

Everything happens on the receiver module. Leave the board's LCD, MENU, UP, DOWN, and SS buttons alone — skipping the menu means no risk of changing gate force, timing, or other settings.

## Steps

1. Have the new remote on hand and know which button(s) to register.
2. Press and hold the receiver's button a few seconds until the **green LED blinks** — learning mode.
3. While it blinks, press the remote button to register.
4. The LED **stops blinking (goes off)** — the code is saved and learning mode is closed.
5. For another button (e.g. separate Open and Close), repeat steps 2–4.
6. Press the remote button again — the gate should respond.

## Test

- From a normal distance, not right next to the receiver, test every programmed button.
- Check Open, Close, and Stop (if used) all behave as expected.

## If It Does Not Work

- LED does not blink: press firmly and hold longer before trying the remote.
- Gate does not respond: repeat, holding the remote button a bit longer while the LED blinks.

The same steps add any further remote or button.
