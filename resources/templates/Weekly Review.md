# Weekly Review

## Clear Obsidian Inbox

- [ ] Open `inbox`.
- [ ] Move project-related notes to `projects`.
- [ ] Move responsibility-related notes to `areas`.
- [ ] Move reference notes to `resources`.
- [ ] Archive inactive or outdated material.
- [ ] Leave only uncertain items that need more thought.

## Clear Computer Desktop

- [ ] Delete files no longer needed.
- [ ] Move project files into the right working folder.
- [ ] Move reference files into the vault or another trusted location.
- [ ] Capture useful context into notes.

## Review Downloads Folder

- [ ] Delete installers, exports, and duplicate files.
- [ ] Move useful files to the right folder.
- [ ] Add notes for files that need future action.

## Review Upcoming Calendar

- [ ] Check the next two weeks.
- [ ] Capture preparation tasks.
- [ ] Create or update project notes for important events.
- [ ] Identify deadlines and decisions.

## Review Active Projects

- [ ] Open `projects`.
- [ ] Confirm each project still has a clear outcome.
- [ ] Identify next actions.
- [ ] Update deadlines.
- [ ] Move stalled or completed projects out of active status.

## Move Stale Notes

- [ ] Move ongoing responsibilities to `areas`.
- [ ] Move reference material to `resources`.
- [ ] Move inactive, outdated, or completed material to `archives`.

## Prompts

What needs my attention next week?

Which project has the highest leverage right now?
